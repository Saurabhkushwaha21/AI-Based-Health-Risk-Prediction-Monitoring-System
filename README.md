# 🧠 AI-Based Health Risk Prediction System

🚀 Live Demo: ai-based-health-risk-prediction-monit.netlify.app

🔗 Backend API: https://ai-based-health-risk-prediction.onrender.com
---

## 📌 Problem Statement
Many people are unaware of their risk of Diabetes and Heart Disease.  
This system predicts health risk using Machine Learning models.

---

## 🧠 ML Approach
- Diabetes Prediction Model
- Heart Disease Prediction Model
- Combined risk calculation

---

## ⚙️ Tech Stack
- Frontend: HTML, CSS, JavaScript  
- Backend: FastAPI (Python)  
- ML: Scikit-learn  
- Deployment: Netlify + Render  

---

## 📊 Features
- User Login (LocalStorage based)
- Health Risk Prediction
- History Tracking
- Dashboard UI
---

## 🚀 Deployment
Frontend: Netlify  
Backend: Render
